# CR-047 - Clarify the Address Consumption Boundary in ADR-006

## Status

Applied — 17 August 2026

## Target

ADR-006 v1.1 → v1.2 Accepted.

## Purpose and Approved Baseline

Propagate CON-006–CON-010 into the existing Address ownership decision.

## Authorised Changes

Define complete Address results, the Vendor Application port and Anti-Corruption Layer, permanent Trading-Location-bound references, immutable repeated resolution, snapshot translation, authorities and semantic/technical failure treatment.

## Non-goals

No production Address matching algorithm, HTTP mapping, Integration Event schema or post-activation address-change design is introduced.

> This Change Request amends only `ADR-006`. It does not amend any other controlled artefact.

## Verification and Completion

The amendment preserves Address ownership, removes the synchronous-resolution ambiguity and agrees with HJ-010/HJ-012 v1.2.
