# CR-050 - Define Address-Derived Registration Information in HJ-104

## Status

Applied — 17 August 2026

## Target

HJ-104 v3.2 → v3.3 Approved.

## Purpose and Approved Baseline

Propagate CON-008 and CON-009 into the authoritative Vendor Registration information contract.

## Authorised Changes

Require a complete Address selection bound to declared Trading Location before submission and define snapshot and authority information.

## Non-goals

No Address search algorithm, wire serialization or Legal Operator Name matching diagnostic is introduced.

> This Change Request amends only `HJ-104`. It does not amend any other controlled artefact.

## Verification and Completion

Required, conditional and optional fields agree with HJ-004 and ADR-006.
