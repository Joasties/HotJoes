# CR-066 — Create ADR-010 Angular for the Vendor Web Client

**Status:** Proposed — awaiting human approval
**Target:** New `ADR-010 - Angular for the Vendor Web Client.md`, v1.0 Accepted
**Applicable concern:** CON-041

## Purpose

Create the lasting architectural decision record required by the explicitly approved selection of Angular as the Vendor Web client development platform.

## Approved decision baseline

The architectural decision-maker explicitly approved the complete CON-041 normative decision on 4 September 2026. The approved working-register row selects Angular on a currently supported major version and confines it to the Web-client implementation boundary.

## Authorised target change

Create ADR-010 with context, the approved decision, rationale, alternatives, consequences and verification. Preserve server-side Domain, Application and HTTP-contract independence and defer detailed Web UI architecture to CON-042.

## Non-goals

Do not select component structure, routing design, state-management mechanism, Registration Session implementation, browser automation, runtime composition or deployment topology.

## Verification and completion

ADR-010 must reproduce the approved decision without extension, use the next sequential ADR number, carry Status Accepted and be registered separately through the ADR-000 change.

This Change Request amends only `ADR-010 - Angular for the Vendor Web Client.md`. It does not amend any other controlled artefact.
