# CR-067 — Create ADR-011 Playwright Test for Browser UI Testing and Automation

**Status:** Proposed — awaiting human approval
**Target:** New `ADR-011 - Playwright Test for Browser UI Testing and Automation.md`, v1.0 Accepted
**Applicable concern:** CON-043

## Purpose

Create the lasting architectural decision record required by the explicitly approved selection of Playwright Test with TypeScript as the browser UI testing and automation platform.

## Approved decision baseline

The architectural decision-maker explicitly approved the complete CON-043 normative decision on 4 September 2026. The approved working-register row selects a currently supported pinned Playwright Test release with corresponding browser binaries.

## Authorised target change

Create ADR-011 with context, the approved decision, rationale, alternatives, consequences and verification. Preserve rendered-browser-only interaction and defer detailed browser-test architecture and security to CON-044.

## Non-goals

Do not select locator conventions, waiting or retry rules, fixtures, environment lifecycle, parallelisation, diagnostic retention/redaction or detailed CI execution.

## Verification and completion

ADR-011 must reproduce the approved decision without extension, use the next sequential ADR number, carry Status Accepted and be registered separately through the ADR-000 change.

This Change Request amends only `ADR-011 - Playwright Test for Browser UI Testing and Automation.md`. It does not amend any other controlled artefact.
